# presence-event-emitter

Embedded device emitting presence events (check-in / check-out) to a central backend.
No local storage. No local timestamps.

## Scope
This component only emits raw presence events.
All interpretation and persistence is delegated to external systems.

## What this is NOT
- HR system
- Payroll system
- Shift management
- Workforce management platform

## Intended users
System integrators, OEMs, industrial system houses.

## Event flow
Presence event is generated by the device and sent immediately over the network
to a central backend.

The backend is responsible for:
- assigning the authoritative timestamp
- validating the event
- persisting or discarding it according to system rules
